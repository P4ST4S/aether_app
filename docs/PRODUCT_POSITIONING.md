# Aether product positioning

## The offer

**Local AI. Right where you work.**

Aether is a native floating assistant for developers and Mac power users who want quick coding, writing, and research help with local inference and explicit control over web access.

The strongest initial audience is developers already comfortable installing Ollama. The current source-build flow asks too much of a general consumer for a one-click purchase pitch.

## What the README should sell

| User need | Message | Evidence in Aether |
| --- | --- | --- |
| Stay focused | Bring help into the current workspace. | Floating panel, global shortcut, Escape dismissal, menu bar presence. |
| Keep inference local | Choose the model that runs on your own Mac. | Loopback-only Ollama integration, installed-model picker, offline chat. |
| Work on real code | Draft, refine, and copy a useful implementation. | Streamed replies, follow-up context, highlighted code, copy controls. |
| Check current information | Connect to the web when the task calls for it. | Explicit Web toggle, page/snippet labels, clickable sources. |
| Trust the presentation | See what is available today. | Genuine app captures, source-build instructions, documented validation and limits. |

Local inference alone is not a unique differentiator: established Mac AI products also offer it. Aether's initial angle is the combination of a focused floating interface, native macOS 26 design, a developer-oriented chat experience, and a simple local/web distinction.

## The demo

Show one practical sequence: open the compact panel, request a real C word counter, refine its whitespace handling, and read a web-grounded answer with a source link. Keep the prompts in English, show genuine output, and disclose edits to pacing. Do not present screenshot sequences as a continuous, unedited screen recording.

The README's immediate call to action is **Get started**, leading to a working source build. There is no public release asset to justify a **Download for Mac** button yet.

## Before a paid public launch

The next commercial work is packaging and distribution: a signed and notarized installer, an upgrade path, and onboarding that makes the Ollama/model download understandable. The owner still needs to choose pricing, support terms, and the project's license. The README deliberately invents none of these.

Do not market an abliterated model as a guarantee of zero refusals or better code. Present the current model as a configurable default. Avoid unsupported security, speed, audience-size, or endorsement claims. Broader voice, accessibility, site compatibility, and long-session testing remain relevant before expanding the audience.

## Research basis

Checked 10 November 2026. These are positioning references, not claims that Aether matches the products' full feature sets.

- [Raycast AI](https://www.raycast.com/core-features/ai): demonstrates jobs and in-workspace interactions before detailing model options. This supports leading with a visible workflow instead of an implementation list.
- [BoltAI](https://boltai.com/): identifies a Mac power-user audience and presents native interaction, model choice, and privacy as concrete benefits. Its local-model support means that “local AI” alone is not an exclusive position for Aether.
- [LM Studio](https://lmstudio.ai/): prominently demonstrates local-model workflows. Aether's README should be equally explicit about what its running app can actually do.
- [GitHub's README guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes): recommends explaining what a project does, why it is useful, how to get started, and where to find help. Detailed engineering material now lives in the technical guide.

No pricing study, customer interviews, or conversion test has been performed. The target audience and messaging above are a practical starting hypothesis based on the product's current behavior and installation requirements.
